## 🎮 Features

The trainer provides a range of controls to customize your gaming experience:

- **Resource Management**: Adjust gold, health, spell slots, and other in-game resources instantly.
- **Game Pacing**: Speed up or slow down game time, control movement speed, and toggle slow motion.

## 📖 How to Use

1. Launch the trainer by double-clicking the downloaded `.exe` file.
2. Start your game (Baldur's Gate 3) in single-player mode.
3. The trainer will automatically detect the game process.
4. Use the on-screen buttons and sliders to activate desired features.
5. Press the "Apply" button or hotkeys (listed in the interface) to enable changes.

If the trainer doesn't detect the game, ensure you're running both as administrator (right-click and select "Run as administrator").

## ❓ Troubleshooting

**Trainer won't open**
- Ensure you have administrator privileges.
- Temporarily disable antivirus software (some may flag trainers as false positives).
- Verify .NET Framework is installed.

**Features not working**
- Make sure the game is running and in single-player mode.
- Check for game updates—trainers are typically designed for specific game versions.
- Restart both the game and the trainer.

**Game crashes after using trainer**
- Reduce the number of active features.
- Disable features one by one to find the problematic one.
- Ensure you're using the latest trainer version.
